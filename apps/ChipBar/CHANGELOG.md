## [Unreleased]

## [3.6.0] - 2026-11-14

- 主页新增 ChipBar Cluster 可排列、可隐藏的全宽液态玻璃磁贴以及独立的只读集群侧边卡片，展示本机与已授权 Mac 的 CPU/GPU、内存、芯片功率、温度和连接状态。
- 集群页面打开时自动搜索 Bonjour 设备；无需手动复制长密钥，改为两台 Mac 核对六位配对码并分别确认，使用 X25519 + HKDF 密钥协商，配对身份与私钥存于钥匙串。监控数据仍通过 AES-GCM 加密认证，未经双方确认不传输性能数据。
- 支持通过外部脚本维护的 cluster-status.json 读取仿真任务状态；缺少实际进度时显示「进度未知」。ChipBar 不启动、不停止、不调度仿真，也不执行远程命令。
- 保留原有 macmon 采样、菜单栏磁贴排布、液态玻璃降级样式与 WidgetKit kinds；仅在用户开启共享后每三秒发送一份有限大小的遥测快照。
- 移除集群侧边页 620pt 的多余固定留白，内容自适应窗口并在设备多时滚动；删除底部重复操作说明，增加可按需展开的雷雳桥接诊断提示。首版须两台 Mac 均运行 ChipBar，尚无独立后台 Agent；具体配置与安全边界见 docs/CLUSTER_MONITOR.md。

## [3.5.1] - 2026-11-11

- 精简「设备与设置」界面：去掉该页单独的风扇转速行和重复的副标题、说明及装饰图标；主页风扇监控和菜单栏风扇显示开关不变。
- 压缩 Apple Silicon 硬件概览与三组设置卡片的间距和内边距，保留系统版本、统一内存、CPU 核心和核心结构信息，减少视觉层级和不必要的留白。
- 进入设备设置页时，原有玻璃窗口只在横向导航动画期间保持主页尺寸；切换完成后再平滑收缩到内容高度，减少页面底部大块空白。内容超过屏幕空间时仍可滚动；遵循系统减少动态效果设置。
- 「应用更新」在尚未执行检查时不再显示重复的默认提示；检查进度、发现新版本和失败信息仍正常显示。新增设置窗口高度行为的回归测试。


## [3.5.0] - 2026-11-10

- 将主页「电源」与「USB-C 输出」合并为一张可自由排列的全宽液态玻璃磁贴，左右分别展示内部/适配器功率和 USB-C 实测输出功率；保留原电源磁贴的持久化标识、排序与隐藏设置，不再创建单独的 USB-C 主页磁贴。
- 新增 AppleSMC D1–D4 逐端口电压、电流与对外供电功率读取；基于 HPM UUID 与 IOKit 物理端口位置配对，缺失或无法核对的读数显示「—」，不使用 USB 协商功率代替实测值。
- 「电源与功率」继续使用原有桑基图，下方新增 USB-C 功率总计、接口协议（Thunderbolt 3/4/5、USB4、USB 3.x）、接口能力与连接速率、可展开的电压电流详情、设备名称与 USB 链路信息；仅对已确认拓扑的 USB 设备归属到具体物理接口。
- 复用既有 3 秒电源采样及 SMC 连接，不新增后台进程；完整 USB 设备树仅在打开电源详情时采集，降低常驻菜单 CPU 开销。二级窗口使用固定尺寸与内部滚动，防止端口行展开时面板整体跳动。
- 保留 macOS 13 起的 SwiftUI 兼容、现有主程序功率/性能采样与 WidgetKit kind；新增端口编号、SMC 数值、缺失数据与布局测试。Mac mini 的内部 DC 功率不视为墙插 AC 实测值。


## [3.4.0] - 2026-11-09

- 高密度液态玻璃 WidgetKit 小组件更新：综合仪表盘支持小／中／大尺寸，另提供可独立添加的储存空间小组件；圆环、功率趋势、逐核心、风扇、ANE 和磁盘信息来自真实快照。
- 新增 Codable 共享 ChipBarSnapshot、快照过期提示、面向预览的独立示例数据，以及 macOS 14+ AppIntent 储存卷选择；macOS 13 保留静态回退方案。
- 保留现有 11 种 WidgetKit kind，避免用户桌面上已添加的旧组件因升级而失效；未改动主程序的 SMC、CPU、GPU 和磁盘硬件采样逻辑。
- 增强简体中文／英文 String Catalog、VoiceOver 动态读数说明以及中尺寸小组件自适应布局；缺失核心数量时显示“—”，不展示示例拓扑。
- 增加 chipbar://main、chipbar://power 与 chipbar://disk/... 深链接，支持从小组件打开对应主程序页面。
- 支持具备有效 Apple Developer Team 签名时使用 App Group；ad-hoc 分发继续使用兼容的本地容器回退。修复 SwiftUI 大型 ViewBuilder 的编译复杂度问题，并增加模型、旧 kind、版本发布的回归检查。

## [3.3.6] - 2026-11-09

- 小组件库精简为**两种**：ChipBar 仪表盘（macOS 小 / 中 / 大三种布局，对应参考图的大型紫色监控、中型横向监控、小型三重圆环）与独立的储存空间小组件（小尺寸）。删除原先各自注册的 CPU / GPU / 内存 / 核心 / 风扇 / ANE / 功率 / 应用等九种多余的小组件；指标仍完整显示在仪表盘内部。
- 按反馈将小组件背景从高饱和紫蓝调整为柔和的灰紫 / 靛蓝 / 蓝青过渡，同时降低圆环与功率曲线发光亮度、提高小字对比度。
- 处理“打开 ChipBar 获取逐核心读数”：新增仅在主程序正常监控时运行的低频 Mach 逐核心采样任务，不依赖主页是否展开，约每 20 秒刷新一次核心缓存，第一轮读取两个间隔 650 ms 的累积滴答样本；并在获得数据后立即写入真实监控快照。
- 加快数据同步：主程序最多每 15 秒向 WidgetKit 扩展容器写一次有效快照，最多约每 120 秒请求一次 WidgetKit 时间线刷新；扩展自身也将下一次时间线请求从 15 分钟提前到 2 分钟。macOS 仍拥有最终刷新预算，可能推迟更新，不能保证秒级实时；延迟时继续展示上一次真实读数并标识快照状态，而非无提示清空。
- 同步修复储存小组件的独立数据链路：在主程序监控运行期间每约 45 秒执行一次有界的内部容量与物理盘状态采集，间隔 1 秒取两次原生 IO 计数以求出实际速度；无需先打开主页，磁盘移除时清理过时外置盘字段，并限制失败重试频率。
- 全面检查三种小组件布局：大卡片根据高度压缩图表与圆环，外接盘和内部盘在大卡片内并排；中卡片采用高度自适应紧凑排布；小卡片压缩安全边距。磁盘名称、数字、容量与速率分别限制一行、调整优先级和最小缩放比例，降低字体溢出及错位风险。
- 添加只注册两个预期小组件、主面板关闭时仍采集核心、缩短刷新时序、没有静态模拟数值及布局家族适配的 CI 回归验证。
- 系统小组件不是常驻实时面板；本次没有增加独立后台常驻进程、每秒 WidgetKit 刷新或新的硬件探针进程。

- 大尺寸采用完整高密度总览（真实芯片名称、功率趋势及均峰值、CPU/GPU/内存三环、逐核心负载、内外置存储、风扇 / ANE / 内部功率）；中尺寸参考横向概览设计，小尺寸参考三重同心环及独立储存卡。布局自适应系统提供的小组件空间。

- 保留已有的原生 Xcode WidgetKit Extension Target、静态 Gallery 描述文字、扩展启动兼容性和自动后台刷新预算（主程序最频繁每分钟写入一次快照、系统最频繁约 15 分钟主动重载一次）。

- 新增松手自动退出、SSD 总开关真实生效与自动 WidgetKit 刷新路径的回归测试。CPU/GPU/SSD 传感器和采样频率维持不变。

- 本次是针对扩展启动失败的修复；构建通过不等于系统已成功显示小组件，安装后需复测 macOS 小组件库及 `chronod` 描述查询结果。

## [3.3.0] - 2026-11-08

- 全新自定义主页磁贴：保留芯片功率趋势、CPU、GPU、内存、CPU 各核心、风扇、ANE、储存空间、电源与应用占用十个独立模块；六轨自适应布局保持原有磁贴宽度与高度比例，支持自由排序、隐藏和恢复默认，位置持久保存在本机。
- 长按磁贴约 0.45 秒进入排列模式，当前磁贴使用轻弹抬起、浮动阴影与选中描边；拖动时原位以半透明占位，邻近磁贴通过连续弹簧重排自动避让。松开后先轻压，再回弹至最终位置；额外支持拖到末尾，快速反复拖动不会积累多组定时器。
- AppKit 菜单玻璃窗口与自定义布局协同：拖动中不重复计算整个窗口高度，仅在进入/退出编辑、放置完成或改变模块可见性时重新测量。退出并重新打开面板时取消未完成的选中状态，但保留布局。
- 采用真正的 macOS WidgetKit 小组件扩展：十个监控模块在系统桌面或通知中心的小组件库中分别可选，支持系统小、中、大尺寸；读取最近一次功率、占用、温度、风扇、核心、内存、储存和应用排行的本地快照。
- 小组件更新由 macOS WidgetKit 调度，而非每秒取样：主应用每分钟最多写入一次受限本地快照，每十五分钟最多主动请求一次系统刷新；过期数据显示提醒，不伪装成实时数据。未新增常驻硬件采样进程。
- 为 WidgetKit 生成和签名独立 arm64 `.appex`，随 ChipBar.app 一同打包。兼容无开发者证书的 ad-hoc 构建，通过扩展沙盒容器共享只读快照；开发者签名环境可使用 App Group。CI 对可执行文件、扩展点、版本、架构和签名进行验证；缺少扩展则阻止正式发布。
- 拖动、释放及页面切换尊重系统“减少动态效果”；macOS 14+ 可放置桌面小组件，macOS 13+ 支持通知中心 WidgetKit。
