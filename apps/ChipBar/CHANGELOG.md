## [2.2.3] - 2026-10-30

- 首页 CPU/GPU 圆环下方功率数字和内存容量字体统一由 12 pt 调为 11 pt，三列都保留相同 16 pt 的文本占位高度；不改变圆环尺寸、线宽、数值与弹簧动画。
- 修复芯片总功率与趋势图上沿的对齐：左侧标题、功率值和单位分配明确行高，左右两列共用 70 pt 的顶部锚点；纵轴刻度文字不会向图表上方溢出，刻度、横向网格及曲线数据使用同一垂直坐标。
- 重新核对储存空间卡片的上下留白；容量读数和占位内容使用相同的 36 pt 双行区域，其他行高固定，正常/未连接/读取中状态都保持居中和对称内边距。

## [2.2.2] - 2026-10-30

- 进一步缩小 CPU/GPU/内存的首页圆环：直径从 80 pt 调整为 74 pt，跑道线宽由 5 pt 增至 6 pt，同时适度缩小内部数字字体；保留动画与内存压力色。
- 芯片总功率信息区与趋势图改为顶部对齐，数值区域宽度 106→92 pt，图表横向空间扩大；纵轴标签区与折线图区间距收紧，并同步调整时间刻度左侧对齐，不更改最近十分钟数据域。
- 重新分配内外置储存卡片垂直空间：内容改为居中布局，固定内容区高度 106→96 pt，内边距 11→10 pt，减少下方过大留白并保留两列对齐及读取/写入速度。
- 修正内置 APFS 启动盘“可用容量”口径：优先采用系统提供的 volumeAvailableCapacityForImportantUsage（含可按需释放的空间），失效或异常时回退至普通 volumeAvailableCapacity；持续确认本地内置启动卷，拒绝越界读数及外置磁盘冒充。补充优先级和回退单元测试。
- 仍按约 30 秒读取容量；macOS 可清理空间和系统缓存会动态变化，显示值不等同于纯物理空闲字节，具体读数需在 macOS 27 设备上与系统设置核对。


## [2.2.1] - 2026-10-30

- 首页进一步紧凑化：CPU/GPU/内存三圆环缩小至 80 pt、面板宽度从 420 pt 减至 394 pt，并缩小主页间距和圆环卡片上下留白；保留原生 Liquid Glass、圆环同步弹簧动画及原有浅蓝色与内存压力色。
- 顶部芯片总功率数字区域收窄至 106 pt，减少与曲线图之间的间隔，增加右侧十分钟功率趋势图的可用横向空间；保留真实时间刻度与平均功率。
- 首页内置硬盘与外置硬盘容量卡新增读取和写入速度（MB/s）；使用已有 IOKit / Disk Arbitration 物理磁盘计数器，面板可见时约每 2 秒更新，容量仍约每 30 秒缓存刷新；首次采样或过期时显示「—」而非虚构读数；同盘多卷显示整盘速率，不误称为卷级 I/O。
- 设置中菜单栏项目、SSD 监控开关、菜单栏功率与刷新频率等选中状态统一改用首页浅蓝色底色、描边与开关轨道，增强开启／关闭的视觉区别，不改变现有偏好保存机制。


## [2.2.0] - 2026-10-29

- 首页视觉升级：保留 ChipBar 现有的青蓝色系、内存压力状态色和原有圆环跑道样式；CPU、GPU、内存三个圆环扩大并作为主视觉。环内字号和百分比层级优化，环下保留实际功率、温度或内存容量信息；不再将内存占用伪装成 ANE 利用率。
- 合并趋势图：仅保留顶部「芯片总功率 + 最近十分钟趋势」模块。移除 CPU/GPU/ANE 小卡片中重复微型趋势线及原独立大图，沿用 2.1.8 修正的本地时间轴，减少视觉负担和绘图成本。
- 保留首页逐逻辑核心 CPU 占用及 P/E/超级核类型展示，应用占用排行保留现有 CPU/GPU/内存/ANE 切换、前三/前五名展开及真实进程记账口径。
- ANE 改为独立紧凑功率条；不展示无法可靠获得的 ANE 总运算占用率，避免指标误读。
- 储存空间改成双列透明容量卡片，以可用容量为主信息、总容量为次信息、细条及百分比表示已用空间；多外接磁盘仍逐卷显示，原有 APFS 去重、磁盘读取周期及未连接提示不变。
- 更新 App 图标为深蓝石墨色圆形衬底配简洁青蓝色心电波形。用可复现的 Swift/CoreGraphics 路径在构建时生成 ICNS，保留原有版本校验和签名流程；标题栏与 Finder 使用同一图标。
- 保留现有系统原生 Liquid Glass、菜单栏读数/偏好、低能耗采样、点击及切换动画、深浅模式和无障碍读数。


## [2.1.8] - 2026-10-29

- 修复功率趋势横坐标时间误读：此前在数据不足两分钟时使用仅显示分/秒的 `mm:ss` 标签（例如 07:44），看起来像时/分并容易被误解为错误时刻；现在始终显示与本机时区一致的 24 小时制 `HH:mm`。
- 横轴固定为真实的最近十分钟，以最新一次采样时间为右端、五分钟前为中点、十分钟前为左端；启动后的一小段采样不再被错误拉伸到整个十分钟宽度。
- 横坐标点位、绘图区间与时间标签采用同一套十分钟时间域，保留中断、睡眠与缺失数值时断线的原有机制。
- 新增固定时间窗口、启动后短时间采样、跨小时与跨午夜的时间标签测试；功率采样率、数据准确度、卡片和液态玻璃动效保持不变。
- 本修复采用 2.1.8 版本号：既有发布流程和 Apple 应用版本字段需要三个数字分段，不兼容四段的 2.1.7.2。


## [2.1.7] - 2026-10-29

- 统一「设备与设置」的选择控件视觉：菜单栏项目不再使用蓝色 `checkmark.circle.fill`，改为与液态玻璃卡片融合的微型滑动开关，选中态采用柔和的中性色底纹、浅色描边及固定大小滑块，避免文字/图标位置跳动。
- 外接 NVMe SSD 监控与「显示 SSD 温度」改用同一套无蓝色勾号的玻璃开关；整行保持可点击、可被 VoiceOver 读取，原有绑定、开关逻辑及用户设置持久化均不改变。
- 菜单栏功率选项改为紧凑的四项分段选择器，移除系统菜单的默认勾选样式；所选指标的背景以原有无过冲的弹簧过渡，延续刷新频率选择器设计。
- 自定义控件仅在用户交互时驱动动画，不增加新的后台计时器、采样任务或监控进程；CPU/GPU/ANE 功能、面板主布局和 Liquid Glass 材质保持不变。


## [2.1.6] - 2026-10-28

- 修复点击「设备与设置 / 返回」后页面在切换结尾出现纵向跳动的问题：保持玻璃窗视口尺寸不变，在页面切换开始阶段准备目的页的可滚动内容高度和顶部偏移，避免动画完成后才突然滚动到顶端。
- 修复「应用占用 → 更多 / 收起」快速连续点按时窗口高度基准过期的问题：统一从稳定的完整折叠高度计算目的大小，不再基于未完成的中途布局值累积伸缩误差；窗口展开之前提前延展滚动文档，消除新增排行行数的临时裁切。
- 反向展开时使用与实际 AppKit / SwiftUI 动画一致的 cubic ease-in-out 曲线估算过渡进度，避免交接瞬间微小错位。
- 统一按钮、选择器、圆环和详情折叠的阻尼弹簧为无过冲的平滑动画；移除应用资源选择器重复的隐式动画，降低连续切换时的二次回弹。
- 新增「更多」反向切换、SSD 详情叠加伸缩及真实贝塞尔缓动的回归测试；不改变原有 Liquid Glass 材质、布局尺寸、功率采样间隔或监测数值。


## [2.1.5] - 2026-10-27

- 优化「应用占用」列表造成的 CPU 开销：仅在用户切换到 GPU 排行时才遍历 IOKit 设备树读取 AGX GPU 客户端；默认 CPU、内存及 ANE 排行不再执行与当前页面无关的昂贵 GPU 扫描。
- 从 CPU / 内存 / ANE 切到 GPU 排行时立即触发包含 GPU 信息的采样，防止复用只包含 CPU 数据的缓存；保留逐应用 GPU 计数器差分、排行展示、切换动画以及原本的实时采样间隔。
- 避免 SwiftUI 监控数值和趋势图每次变化时都要求 AppKit 重新测量整页 intrinsic height：只在状态提示、SSD 信息或显隐状态可能改变页面布局时安排测量，继续沿用原有面板展开/收起和液态玻璃动画时序。
- 修复页面关闭或指标切换后后台扫描结果仍可能发布至画面的问题，取消的任务不再覆盖新状态；新增 CI 测试覆盖 GPU 跳过及指标切换时的缓存刷新策略。
- 不改变液态玻璃设计、功能开关、芯片功率监控及 macmon 独立进程的采样逻辑；CPU 节省幅度需在用户 Mac 上用实际计数器测量。


## [2.1.4] - 2026-10-26

- 修复「检查更新」能发现新版本、但「下载并安装」无法可靠完成自动替换的问题：已完成 SHA-256 和代码签名校验的版本由独立安装辅助进程接管，先关闭当前 ChipBar，再备份旧应用、安装新应用、通过 LaunchServices 启动并确认新进程运行，避免运行中覆盖与同 Bundle ID 重启冲突。
- 若替换或新版本启动失败，优先恢复旧版并重新启动，记录失败原因供下一次打开「设备与设置」查看。安装辅助进程不需要 root、sudo 或 shell 注入。
- 更新状态对象在关闭和重新打开菜单面板后继续保留，避免下载失败信息被界面重新创建而清空；成功升级后清除旧错误。
- 对同卷替换的旧版备份、换新操作和失败回滚添加自动测试；不可写、受 Homebrew 管理或 App Translocation 的应用仍需先使用可写安装位置或其软件包管理器升级。

- 透明悬浮窗口让系统玻璃呈现桌面背景，支持明暗模式和小屏滚动。
- 较旧 macOS 自动使用系统磨砂玻璃，支持点击外部或 Esc 关闭面板。
- 保留 1.0.3 的应用图标和原有趋势图。

## [1.0.3] - 2026-10-09

- 新增深色芯片、青蓝色闪电与波形的应用图标。
- Finder / 应用程序目录与弹窗标题使用统一图标。
- 构建自动生成普通及 Retina 图标，并在发布前检查 ICNS 资源完整性。

## [1.0.2] - 2026-10-08

- 修复菜单栏只显示闪电图标、不显示实时功率数字。
- 使用原生状态栏与弹窗管理，修复顶部空白及设置展开后的高度缓存。
- 小屏幕上自动限制弹窗高度并滚动显示完整设置。
- 趋势时间标签使用三个固定位置，避免末端截断；短时间采样显示分秒。

- 自动工作流使用 Node.js 24 运行环境。

## [1.0.1] - 2026-10-08

- 统一版本号、应用打包、GitHub Release 与 Homebrew 更新。
- 增加自动构建、解析测试及进程故障检查。

## [1.0.0] - 2026-10-08

- 原生 macOS 菜单栏功率、温度与趋势监控。
- 可调刷新间隔、暂停、自动重试与 macmon 路径设置。
- M1 Pro 实测与首次 arm64 应用发布。
