# 更新记录

## [Unreleased]

## [1.3.6] - 2026-10-21

- 菜单栏数值与英文标签分层：单值列上排 10 pt、下排标签 7 pt，沿列中心线对齐并垂直居中；右侧网速、磁盘双行数值保持 9 pt。
- 新增可独立开关的外置硬盘 ER / EW 速度列，多盘合计、未连接时隐藏，复用原有系统 I/O 计数和刷新时钟，不增加 SMART 轮询；原有磁盘总速度含义不变。
- 修复 10 秒采样间隔下，调度误差使磁盘计数差分被判为超时、持续显示不可用的问题。

## [1.3.5] - 2026-10-20

- 微调菜单栏字号：数值从 10 pt 调为 9 pt，POWER、CPU、GPU、SSD、RPM 等说明标签为 7.5 pt；网速和磁盘读写的上下排数值保持同样字号，文字测量同步采用对应字体。

## [1.3.4] - 2026-10-20

- 菜单栏按设置中的 1 / 2 / 5 / 10 秒间隔统一提交完整快照，网速与硬盘计数共用刷新时钟，采样异步完成时不再分批改变数字；SSD 保留 30 秒 SMART 读取周期。
- 菜单栏上下排统一为 10 pt、中等字重的等宽数字字体，放大原先较小的数值和标签。
- 相同快照跳过显示更新，未变列复用文字测量结果，窗口宽度只在需要时调整；展开动画不再重复刷新菜单栏。
- 关闭面板且未显示菜单栏网速时停止网络采样，菜单栏磁盘采样不再扫描卷容量；暂停 / 睡眠停止显示刷新时钟，降低后台唤醒频率。

## [1.3.3] - 2026-10-20

- 菜单栏改为双排紧凑列：功率、CPU / GPU 占用率、SSD 温度和风扇转速以数值配短标签，网速及硬盘读写上下成对显示；等宽数字、按列保留宽度并以细分隔线区分。
- SSD 综合温度显示开关统一放到菜单栏选项组，沿用原有偏好；风扇显示最高转速，悬停仍可查看全部风扇数值。
- 修复设置展开后每次数据刷新都把滚动位置拉回底部的问题：展开完成只定位一次，随后保留手动滚动位置，内容变高或变矮时保持顶部偏移并限制有效范围。
- 面板采用 160 ms 快速缓出打开、100 ms 关闭，Esc 即时退出；保留同步展开及减少动态效果支持。增加紧凑显示与设置滚动回归检查。

## [1.3.2] - 2026-10-20

- 菜单栏可独立显示功率、CPU / GPU 占用率、风扇 RPM、上传 / 下载速度及硬盘读写速度，支持隐藏 Logo，自动保存设置并保留菜单入口。
- CPU / GPU 功率卡片新增整体活跃时间占比；ANE 占用率缺失时明确提示不可用，风扇复用 macmon 原始读数。
- 网速使用系统 64 位接口计数，每秒刷新；菜单栏硬盘 I/O 使用原生驱动计数，每两秒合计可读取的内置和外接物理磁盘，不依赖 SMART。
- 新增采样差分与异常数据测试；菜单栏等宽数字及宽度保留减少跳动，沿用面板同步展开动效并遵循减少动态效果。

## [1.3.1] - 2026-10-16

- 将 ChipBar 连同完整提交历史导入 macmon Fork 的 `apps/ChipBar/`，保留上游源码与 MIT 许可证。
- 构建、测试和发布流程适配新目录；ChipBar 在 `chipbar` 分支维护，以 `chipbar-v…` 标签独立发布。
- Homebrew Cask 放在仓库根目录，旧仓库保留历史下载并作为兼容安装入口。本次不更改应用功能和硬件采样实现。

## [1.3.0] - 2026-10-16

- 外接 SSD 摘要新增剩余可用空间及实时读取 / 写入速度（MB/s），使用系统原生卷容量与驱动字节计数，面板可见时每 2 秒更新速度、每 30 秒更新空间；无 smartctl 也可查看。
- 硬盘传感器、SMART 状态与各卷空间默认收起，提供“详情 / 收起”与约 0.2 秒同步窗口动画；遵循减少动态效果，重新打开面板保留展开选择。
- APFS 共享空间按卷显示，不重复累加；缺失计数器、断连、计数器复位与首样本显示不可用或重新建立基线。

## [1.2.0] - 2026-10-16

- 新增可选外接 NVMe SSD SMART 温度监控，支持综合温度、保留编号的独立传感器、型号及健康状态；菜单栏可附加多盘最高综合温度。
- 普通用户优先读取 smartctl JSON；支持标准 Homebrew 路径、自选可信程序、手动桥接类型和用户预先配置的非交互 sudo，缺失程序 / 权限 / SMART 透传失败明确提示。
- 后台串行读取，每轮完成后等待 30 秒，不存历史；处理睡眠、暂停、退出、断连、重插编号变化及过期数据，限制进程时间和输出大小。
- 增加真实脱敏 TiPlus7100s 夹具、解析 / 发现 / 故障测试、实盘诊断与安装权限文档。通过功能分支和 PR 完成验证。

## [1.1.3] - 2026-10-15

- 展开 / 收起改由同一段约 0.2 秒过渡同步推进排行、说明、设置高度与窗口尺寸，移除“内容先跳到最终布局、窗口再追赶”的独立动画；支持在当前位置反向收起。
- 滚动区域明确关闭矩形边框和焦点描边，整个玻璃内容统一圆角裁切；展开结束后重建窗口阴影，处理底部两角露出的矩形边线。
- 设置区域按实际内容测量高度，展开时同步显示，隐藏后禁用其控件；关闭面板时取消正在进行的内容过渡。

## [1.1.2] - 2026-10-15

- 菜单栏面板改用原生 nonactivating panel，移除打开时的应用激活调用，保留原应用的活动状态与窗口阴影。
- 由 AppKit 统一执行顶部锚定的窗口尺寸动画，移除全页 SwiftUI 隐式布局动画并固定内容顶部，修复标题和前三行在展开中上下移动；面板向下展开、向上收起。

## [1.1.1] - 2026-10-15

- 应用排行左侧的空方框改为排名数字，去除“应用占用”按钮的蓝色焦点外框，面板打开时不自动聚焦首个按钮。
- 应用占用和设置展开 / 收起增加约 0.2 秒缓入缓出过渡；前三行保持稳定，额外两行、说明与箭头平滑变化，遵循系统“减少动态效果”。
- 将面板尺寸和位置合并更新，保持顶部锚点，避免每次数据刷新重复调整玻璃与滚动视图，减少展开 / 收起时的整页闪动。

## [1.1.0] - 2026-10-15

- 新增“应用占用”排行，默认直接展示 CPU / GPU 占用前三名，展开可查看前五名和说明，同一应用内的辅助进程合并统计。
- CPU 按逻辑核心计算百分比；GPU 按 AGX 驱动时间差计算，并注明其与整机 GPU 利用率的区别。无可用计数器时明确提示。
- 新增 macOS 15+ 的 ANE 记账内存展示；与 ANE 计算利用率明确区分，不推算逐应用计算百分比。
- 缩小合计功率数字、分项卡片、趋势图与区域间距，让前三名直接可见时面板仍然紧凑。
- 排行仅在面板可见时采样，至少两秒更新一次，暂停和睡眠时停止，不保留进程历史。

## [1.0.7] - 2026-10-14

- 原生鼠标按下时固定菜单栏按钮本次目标状态，由按钮动作完成一次切换；修复点按与失焦回调交错导致的重新展开。
- 失焦自动关闭合并为可取消的延迟请求，按钮操作优先；使用菜单栏窗口层级及原生窗口编号识别事件，去除对瞬时鼠标按键和光标位置的关闭判断依赖。
- 增加独立进程的鼠标测试驱动与连续点击检查；锁屏时拒绝执行实际点击测试。

## [1.0.6] - 2026-10-13

- 修复真实鼠标再次点击菜单栏图标时，失焦通知和全局鼠标监视器抢先收起、随后按钮动作又重新展开的问题。
- 增加经 WindowServer 派发的鼠标按下/抬起回归检查，核对连续点击后的目标状态与实际窗口可见状态。

## [1.0.5] - 2026-10-13

- 菜单栏点击一次展开、再次点击收起；面板使用 AppKit 短淡入/淡出，支持动画中途反向切换，并尊重系统“减少动态效果”。
- 修复长时间读取 macmon 输出时，Foundation / JSON 临时对象留在读取线程的 autorelease pool 中持续累积的问题；stdout 每块、JSON 每行和 stderr 每块分别释放临时对象。
- 关闭面板时移除 SwiftUI 仪表盘，避免隐藏的趋势图继续刷新；重新打开保留历史、趋势指标与设置状态。
- 用有界 SwiftUI 路径绘制趋势，修复面板持续更新时原 Swift Charts 趋势区域的内存增长；保留功率、时间刻度、均值与缺失采样断线。
- 增加读取线程与完整面板的加速内存检查脚本，记录包含压缩内存的 physical footprint。
